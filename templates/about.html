About WeatherPulse

WeatherPulse is a production-ready, full-stack weather dashboard built to demonstrate real-time API integration, server-side caching mechanisms, dynamic AQI calculation algorithms, and clean horizontal UI/UX engineering.

🛠️ Tech Stack

Python 3 Flask OpenWeatherMap API HTML5 CSS3 / Grid Layout Vanilla JavaScript (ES6+)

⚡ Key Technical Achievements

⚡

10-Minute Server Caching

Implemented an in-memory dictionary cache in Python with TTL expiration (`CACHE_TTL = 600`) to minimize external OpenWeatherMap API calls and conserve rate-limit quotas.

🍃

US EPA AQI Algorithm

Converts raw PM2.5 concentration (μg/m³) to standard US EPA Air Quality Index values (0–500 scale) and dynamically positions a multi-color gradient slider indicator.

📅

5-Day Forecast Parsing

Fetches 40-entry 3-hour forecast data and aggregates one entry per day (selecting noon slots), displaying high/low temperature ranges and condition descriptions.

🔄

Unit Toggle & LocalStorage

Instant client-side switching between Celsius (°C) and Fahrenheit (°F) with `data-celsius` DOM attributes, along with `localStorage` city persistence for rapid re-searches.
