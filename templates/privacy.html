Privacy Policy

Last Updated: August 13, 2026

1 Data Collection & Privacy

WeatherPulse is built strictly as an educational full-stack software portfolio application. The application does not require user accounts, email registration, passwords, or personal identity tracking. We do not collect, harvest, store, or sell any personal data or personal identifying information (PII).

2 Local Browser Storage

To enhance user experience, WeatherPulse utilizes your browser's client-side localStorage API. This storage is used exclusively to retain a history of your 3 most recently searched city names so you can quickly re-search them.

This data remains strictly stored on your personal device within your web browser. It is never transmitted to any external analytics servers, databases, or third-party tracking networks, and you can clear it at any time by clearing your browser cache.

3 Third-Party API Services

When you submit a city search, the city name string is sent via secure HTTP requests from our backend server to the OpenWeatherMap API to retrieve current weather, 5-day forecast, and air pollution datasets.

WeatherPulse does not attach any personal identifiers to these API queries. For further details on how OpenWeatherMap processes API traffic, please refer to the official OpenWeatherMap Privacy Policy.

4 Contact Information

If you have any questions, suggestions, or technical feedback regarding this portfolio application or its privacy practices, please feel free to connect via GitHub or LinkedIn.
